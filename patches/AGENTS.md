# patches

## Purpose

The exported series: `patches/<version>/<name>/` holds the patches of one
series for one kernel series.

## Ownership

- Each export directory: the `.patch` files, `series` (quilt order),
  `source` (branch, base tag, tip, date, pull request) and `README.md`.
- The pins of the exports are the gitlinks under `series/`, owned by the
  root.

## Local Contracts

- Everything here is generated by `tools/export-series.sh`; never edit it
  by hand. Change the branch and re-export.
- An export and its pin change in the same commit.
- Exports of older kernel series are history and stay unchanged; only the
  current kernel series is exported again.
- Exports apply with `git am` to the base tag named in `source`.

None.

## Verification

- `tools/check-series.sh <version> [<name>...]`
